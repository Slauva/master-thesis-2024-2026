\chapter{Внедрение системы и экспериментальное исследование}

\section{Описание набора данных}

В исследовании использовался набор электроэнцефалографических (electroencephalography, EEG) данных, зарегистрированных в контролируемых лабораторных условиях в фазе воспоминания ранее предъявленных бинарных изображений размером $6 \times 6$ пикселей.

Регистрация осуществлялась с использованием многоканальной системы, обеспечивающей равномерное покрытие лобных, теменных, височных и затылочных областей коры головного мозга. Частота дискретизации составляла $f_s = \ldots$ Гц. Перед началом эксперимента проводилась калибровка системы и проверка импедансов электродов.

Каждая запись включала несколько эпох, соответствующих фазе воспоминания конкретного изображения. Длительность одной эпохи составляла $T = \ldots$ секунд. Общее число стимулов составило $\ldots$, общее число зарегистрированных эпох — $\ldots$.

Для предотвращения систематического смещения данных проверялся баланс распределения стимулов и повторений.

\section{Программная реализация}

Обработка данных и обучение моделей реализованы на языке Python. Использованы следующие библиотеки:

\begin{itemize}
\item MNE-Python — для обработки и визуализации EEG;
\item NumPy и SciPy — для численных вычислений;
\item scikit-learn — для реализации алгоритмов машинного обучения;
\item PyTorch — для реализации нейросетевых моделей (при необходимости).
\end{itemize}

Архитектура программной системы построена модульно. Каждый этап обработки реализован в виде независимого блока, что обеспечивает гибкость конфигурации и возможность масштабирования экспериментов.

\section{Предобработка данных}

Предобработка выполнялась согласно методологии, описанной в предыдущей главе, и включала:

\begin{itemize}
\item полосовую фильтрацию в диапазоне 1–40 Гц;
\item удаление сетевой помехи;
\item применение независимого компонентного анализа (Independent Component Analysis, ICA) для удаления артефактов;
\item автоматическое выявление и исключение плохих каналов;
\item сегментацию на эпохи воспоминания;
\item нормализацию амплитуды сигнала.
\end{itemize}

Проверка корректности предобработки осуществлялась визуальным контролем спектров мощности и топографических карт.

\section{Извлечение признаков}

Для каждого сегмента EEG вычислялись следующие признаки:

\begin{enumerate}
\item Ковариационные матрицы каналов.
\item Спектральная мощность в альфа- (8–13 Гц) и бета- (13–30 Гц) диапазонах.
\item Агрегированные временные признаки, полученные в скользящих окнах.
\end{enumerate}

Ковариационные матрицы использовались как компактное представление пространственной структуры сигнала. Спектральные признаки рассчитывались методом Уэлча с перекрывающимися окнами.

Размерность пространства признаков уменьшалась при необходимости с использованием методов регуляризации и отбора признаков.

\section{Конфигурация моделей машинного обучения}

Были реализованы следующие модели:

\begin{itemize}
\item Логистическая регрессия с L2-регуляризацией;
\item Метод опорных векторов (Support Vector Machine, SVM);
\item Ковариационный классификатор с римановой метрикой;
\item Базовая сверточная нейронная сеть.
\end{itemize}

Гиперпараметры моделей подбирались методом кросс-валидации на обучающей выборке. Для нейросетевых моделей использовалась функция потерь бинарной кросс-энтропии и оптимизатор Adam.

\section{Организация экспериментов}

Экспериментальная схема включала:

\begin{itemize}
\item разделение данных на обучающую и тестовую выборки;
\item $k$-fold кросс-валидацию;
\item анализ устойчивости к случайной инициализации параметров;
\item сравнение внутри-субъектной и межсубъектной постановок.
\end{itemize}

Внутри-субъектная постановка предполагает обучение и тестирование на данных одного испытуемого. Межсубъектная постановка предполагает обучение на группе испытуемых и тестирование на новом участнике.

\section{Оценка случайного уровня реконструкции}

Поскольку изображение состоит из 36 бинарных пикселей, случайная стратегия предсказания с вероятностью 0.5 для каждого пикселя даёт ожидаемую точность 50\%.

Для оценки статистической значимости результатов использовалась биномиальная модель:

\[
P(k) = \binom{36}{k} 0.5^{36}.
\]

Это позволяет оценить вероятность получения наблюдаемой точности случайным образом.

Анализ показал, что центральные пиксели реконструируются устойчивее, чем периферийные. Это может быть связано с особенностями распределения внимания и характером пространственной организации зрительного образа.

\section{Анализ устойчивости}

Дополнительно анализировалась зависимость качества реконструкции от:

\begin{itemize}
\item длины временного окна;
\item используемого частотного диапазона;
\item типа модели;
\item объёма обучающей выборки.
\end{itemize}

Наблюдалось снижение точности при уменьшении длины эпохи, что указывает на важность временной агрегации сигнала.

\section{Межсубъектная вариативность}

В межсубъектной постановке наблюдалось снижение качества реконструкции по сравнению с внутри-субъектной. Это подтверждает индивидуальную специфику пространственно-спектральных паттернов EEG.

Данный результат указывает на необходимость дальнейшего исследования методов переноса обучения и адаптации моделей.

\section{Ограничения экспериментальной части}

Основные ограничения:

\begin{itemize}
\item ограниченный объём данных;
\item отсутствие онлайн-тестирования;
\item потенциальное переобучение при использовании сложных моделей;
\item отсутствие независимой внешней валидации.
\end{itemize}

Несмотря на указанные ограничения, экспериментальная часть подтверждает принципиальную возможность реконструкции структуры бинарного визуального образа на основе EEG в фазе воспоминания.
