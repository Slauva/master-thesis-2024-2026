\chapter{Дизайн и методология системы реконструкции визуальных стимулов}

\section{Общая постановка задачи}

Настоящая работа посвящена разработке методологии реконструкции бинарных визуальных стимулов размером $6 \times 6$ пикселей на основе многоканальных сигналов электроэнцефалографии (electroencephalography, EEG), зарегистрированных в фазе воспоминания ранее предъявленного изображения.

В отличие от задач декодирования категорий стимулов, где выходом модели является одна метка класса, в данной работе требуется восстановление пространственной структуры изображения. Таким образом, задача имеет характер многовыходной бинарной классификации.

Пусть $X_i \in \mathbb{R}^{C \times T}$ — матрица EEG-данных для $i$-й эпохи, где $C$ — число каналов, $T$ — число временных отсчётов. Целевой отклик задаётся бинарной матрицей:

\[
Y_i \in \{0,1\}^{6 \times 6}.
\]

Для удобства представления изображение векторизуется:

\[
\mathbf{y}_i \in \{0,1\}^{36}.
\]

Требуется построить параметризованное отображение:

\[
f_\theta: \mathbb{R}^{C \times T} \rightarrow \{0,1\}^{36},
\]

где $\theta$ — параметры модели.

Оптимизация параметров осуществляется посредством минимизации функции потерь:

\[
\mathcal{L}(\theta) = \sum_{i=1}^{N} \ell(f_\theta(X_i), \mathbf{y}_i),
\]

где $\ell$ — бинарная кросс-энтропия либо Hamming loss.

\section{Архитектура системы}

Разрабатываемая система реконструкции включает следующие функциональные модули:

\begin{enumerate}
\item Модуль регистрации EEG.
\item Модуль предобработки сигнала.
\item Модуль извлечения признаков.
\item Модуль машинного обучения.
\item Модуль реконструкции изображения.
\item Модуль визуализации и оценки качества.
\end{enumerate}

Система реализована по принципу последовательной обработки данных. На каждом этапе осуществляется преобразование представления сигнала с целью повышения информативности и снижения размерности пространства признаков.

\section{Экспериментальный протокол}

Эксперимент включал две фазы:

\begin{enumerate}
\item Фаза предъявления и запоминания изображения.
\item Фаза воспоминания при регистрации EEG.
\end{enumerate}

Испытуемым предъявлялись бинарные изображения размером $6 \times 6$ пикселей. После периода запоминания следовал временной интервал, в течение которого участник воспроизводил изображение мысленно при фиксации взгляда.

Регистрация EEG осуществлялась многоканальной системой с частотой дискретизации, обеспечивающей анализ диапазона 1–40 Гц. Длительность эпох воспоминания выбиралась таким образом, чтобы обеспечить формирование устойчивого когнитивного состояния.

\section{Предобработка сигналов}

Предобработка включает следующие этапы:

\begin{itemize}
\item полосовая фильтрация (1–40 Гц);
\item удаление артефактов методом независимого компонентного анализа (Independent Component Analysis, ICA);
\item автоматическое выявление плохих каналов;
\item сегментация сигнала на эпохи;
\item нормализация амплитуды.
\end{itemize}

Корректность предобработки критически влияет на устойчивость последующих пространственных и спектральных признаков.

\section{Пространство признаков}

Для построения компактного представления данных определяется отображение:

\[
\phi: \mathbb{R}^{C \times T} \rightarrow \mathbb{R}^{d}.
\]

Рассматриваются следующие типы признаков:

\begin{enumerate}
\item Ковариационные матрицы каналов.
\item Спектральная мощность в альфа- и бета-диапазонах.
\item Временные агрегированные признаки.
\item Комбинированные пространственно-спектральные признаки.
\end{enumerate}

Использование ковариационных матриц позволяет учитывать межканальные зависимости, что особенно важно при низком пространственном разрешении EEG.

\section{Стратегии обучения модели}

Реконструкция изображения реализуется в форме многовыходной бинарной классификации. Рассматриваются три возможные стратегии:

\begin{enumerate}
\item 36 независимых классификаторов;
\item единая многовыходная модель;
\item регрессионная модель с последующей бинаризацией.
\end{enumerate}

В текущей реализации используется пиксельная классификация с независимыми выходами.

Для предотвращения переобучения применяются:

\begin{itemize}
\item L2-регуляризация;
\item ограничение сложности модели;
\item кросс-валидация;
\item снижение размерности признаков.
\end{itemize}

\section{Метрики оценки}

Качество реконструкции оценивается с использованием следующих метрик:

\begin{itemize}
\item Pixel Accuracy;
\item Hamming Distance;
\item F1-score;
\item Intersection over Union (IoU).
\end{itemize}

Дополнительно проводится анализ устойчивости результатов к различным разбиениям данных.

\section{Ограничения методологии}

Основные ограничения:

\begin{itemize}
\item низкое пространственное разрешение EEG;
\item ограниченный объём выборки;
\item межсубъектная вариативность;
\item возможное переобучение модели.
\end{itemize}

Несмотря на указанные ограничения, предложенная методология обеспечивает формализованную постановку задачи реконструкции визуальных образов малого разрешения.
